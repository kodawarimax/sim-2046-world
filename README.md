# 人生＆未来の街づくりRPGシミュレータ（2026〜2076）

2026年から2076年までの50年間で、仕事・お金・街・建築がどう変わるかを、ゲーム感覚で体験できるシミュレータです。

## 遊び方

`index.html` をブラウザで開くだけで動きます（ビルド不要・外部ライブラリなし）。

- **開拓ストーリーRPG**：全10章（2026〜2076年）。毎章3つの選択肢から選んで町を育て、最後にS〜Cランクが決まります。
- **高校生モード／社会人モード**：開始時に選択。社会人モードでは利回り・金利・人件費・補助金などの実務判断になります。
- **ランダム事件**：金利上昇・大地震・資材高騰・人手不足・景気後退など。同じ選択でも結果は毎回変わります。
- **操作**：島をクリック、十字キー／WASDで移動、Spaceでダッシュ調査、1・2・3キーで選択。
- そのほか、すごろく・ボスバトル・ルーレット、不動産・建築・ゼネコン業界の50年予測などのタブがあります。

## テスト

```bash
node --test tests/codex_isometric_rpg.test.cjs
```

## 注意

- ゲーム内の数値・確率・人物・企業はすべて架空、または学習用に調整した値です。実際の投資判断や将来予測には使わないでください。
- 画像（`assets/`）はAIで生成したイメージです。
